How the Dashboard Actually Works

Three things that happen every time you use the dashboard — how a number gets calculated, how a filter changes what you see, and what happens when you click directly on a chart. Each one walks through a real example.

Walkthrough 1

How a Number Gets Calculated

Example: the "Invoice Amount" tile at the top of the dashboard

1

You open the dashboard in your browser.

2

The page asks one simple question: "what's the total invoice amount?"

3

That question is sent to a small piece of backend code written specifically to answer it.

this code lives inside Fabric itself, right next to the data
4

That code runs a real calculation directly against your actual invoice records — all 1.3 million of them — and adds them up.

the adding-up happens inside the database, not in the browser
5

Only the final answer travels back — one number, not the 1.3 million rows behind it.

6

The page displays it: AED 2.91B

The key point: nothing is calculated ahead of time and stored. Every single number on the page is worked out fresh, right at the moment you look at it.

Walkthrough 2

How a Filter Changes What You See

Example: picking "Year: 2025" from the dropdown

1

You open the Year dropdown and pick 2025.

2

The page remembers one thing: "the user only wants to see 2025."

3

It re-asks every single question on the page again — but this time, each one adds "...only for 2025" to what it's asking.

the KPIs, every chart, and the invoice table all do this at once
4

Each answer comes back recalculated for just 2025, and every number and chart on the page updates together.

The key point: there's one shared filter for the whole page, not a separate one per chart. Change it once, and everything responds — because they're all re-asking their questions with the same condition attached.

Walkthrough 3

How Clicking a Chart Works

Example: clicking the "DSO" bar in Top Customers

1

You click directly on a bar in a chart — say, a customer's name.

2

The page treats that exactly the same as if you'd picked it from a dropdown.

there's no real difference between a click and a dropdown pick under the hood
3

The shared filter updates, and every chart and number re-asks its question — same as Walkthrough 2.

4

Click that same bar again, and the page checks: "is this already selected?" — if yes, it removes the filter instead of adding it.

that's the on/off toggle behavior

The key point: a chart click isn't a special feature bolted on — it's just a second way of setting the exact same filter that the dropdowns use.
